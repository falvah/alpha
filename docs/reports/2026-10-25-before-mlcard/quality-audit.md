# Аудит безопасности, удобства и чистоты — 25 октября 2026

Проверены установленное окружение, серверный код, формы, API, скоринг, шаблоны, JavaScript и запущенное приложение. Изменения проверялись в отдельной базе; рабочие данные не использовались для атакующих HTTP-запросов.

## Безопасность и корректность

| Найденная проблема | Исправление |
|---|---|
| Клиент мог передать собственные результаты проверок через `/scenarios/` и получить автоматическое одобрение | Клиентский маршрут удалён. Скоринг и загрузка обогащения доступны сотруднику; контрольные заявки создаются только локальной командой начальной загрузки |
| После уточнения заявки мог использоваться скоринг по прежним данным | Установлен `checks.needs_refresh`; одобрение и принятие блокируются до свежего расчёта сотрудником |
| Повторяющиеся JSON-ключи и несколько алиасов одного поля молча принимались | Общий строгий парсер для формы и API отклоняет неоднозначные объекты |
| Сумма с долями копейки округлялась без отказа | Денежные поля принимают не более двух десятичных знаков |
| Обозначение валюты принималось внутри числа (`9руб00000`) | Разрешён только суффикс валюты; посторонний текст внутри числа отклоняется |
| Поступления за 24 месяца допускались у компании возрастом один день | Период поступлений сверяется с возрастом компании |

Исправлены **6 подтверждённых проблем доступа, актуальности и валидации**. Для оценки масштаба: первые две касаются доверия к решению, остальные четыре — непротиворечивости входных данных. Это не заявление об отсутствии других уязвимостей.

Выполнено 107 серверных тестов, включая 336 подстановок в 28 полей. Проверены отрицательные и бесконечные числа, неверные типы, обратные названия полей, SQL-строки, XSS, чрезмерная вложенность JSON и подмена роли. На настоящем сервере прошли 102 проверки: 104 HTTP-запроса, ответов 5xx нет. Два параллельных создания дают один UUID; два параллельных принятия — одно событие завершения. Проверки чужих заявок, API, документов и графиков возвращают 404; действия чужой роли и запросы без CSRF отклоняются.

PDF не считается безопасным только по сигнатуре: он сохраняется как недоверенный бинарный объект, не исполняется и скачивается как attachment/octet-stream с nosniff. Антивирусное сканирование не реализовано.

## Удобство

- Реальными HTTP-запросами проверены 8 клиентских и 3 служебных страницы.
- Сохранены полное одобрение, встречное предложение со снижением суммы и блокировка; клиент отдельно подтверждает условия.
- В очереди исправлен пустой балл новой карты: сотрудник видит PD в процентах либо требование пересчёта.
- Убраны учебные подписи, примеры скоринга в клиентской навигации, демоставки и инструкции по внутренним файлам на странице входа.
- Калькулятор очищает устаревший результат и ссылку при редактировании; запоздавший ответ не перезаписывает новый. Сбой сети показан пользователю. Это проверено 5 JavaScript-тестами.
- Генератор PDF больше не вставляет одинаковые финансовые показатели во все заявки. Для 7 ранее созданных системных документов обновлены показатели; 4 остальных документа сохранены побайтово. Снимки, суммы решений и история статусов не изменены.

Визуальная адаптивность и удобство для реальных пользователей в этой проверке не измерялись. Оценки вроде «UX 9/10» не присваивались.

## Зависимости и чистота кода

| Компонент | Почему оставлен |
|---|---|
| Django | ORM, формы, шаблоны, авторизация, CSRF |
| asgiref | Обязательная зависимость Django |
| sqlparse | Обязательная зависимость Django |
| WhiteNoise | Отдача локальной статики и manifest |
| Gunicorn | WSGI-сервер, поточный worker |
| tzdata, только Windows | Условная зависимость Django для часовых поясов |

Удалён `packaging` из lock-файла и `.venv`: установленная версия Gunicorn использует его только в необязательных extras, а выбранному поточному worker он не нужен. `pip check` и проверка Gunicorn прошли. npm-зависимостей нет.

Дополнительно отключён неиспользуемый управляющий Unix-сокет Gunicorn: при первом запуске он пытался записать файл в недоступный системный каталог. Повторный запуск с `--no-control-socket` прошёл без этой ошибки.

Из runtime вынесены тестовые заглушки обогащения, JSON-наборы собраны в `fixtures/scorecard`, удалена лишняя обёртка тестового модуля. Удалены 3 неиспользуемых импорта. AST-проверка runtime-кода не выявила других кандидатов на неиспользуемые импорты. Это локальный статический анализ, а не доказательство отсутствия любого мёртвого кода.

Длинная функция скоринга разделена на оценку факторов и формирование решения; максимальная длина runtime-функции уменьшилась со 122 до 68 строк. Метрика считает физические строки Python, включая пустые строки; сжатые HTML/CSS не оцениваются по ней.

## Очистка

Через промежуточный каталог в `доки` перенесены и затем удалены **74 файла, 679 108 байт**: 28 устаревших артефактов и скриптов, 46 файлов кэша. Старые хешированные статические ресурсы отдельно удалены штатной пересборкой `collectstatic --clear`.

Сохранены база, пользовательские документы, миграции, действующие тесты, рабочее окружение и исходные материалы задания. Они нужны для работы либо воспроизводимости. `staticfiles/` пересобран, поскольку используется сервером. В Docker копируются только runtime-каталоги; документация, тесты, `.data` и `.venv` в образ не попадают.

Точный перечень удалённого с SHA-256: [журнал очистки](cleanup-manifest.json). Служебные каталоги среды `.git`, `.agents`, `.codex`, `.aws` не изменялись.
