# Структура проекта

```text
ALFA_HACKATON/
├── .git/                       # Единственная история Git, remote origin сохранён
├── config/                     # Настройки Django, корневые URL, WSGI
├── credit/                     # Рабочее Django-приложение
│   ├── models.py               # Компания, заявка, документы, события, уведомления
│   ├── forms.py                # Проверка пользовательского ввода
│   ├── views.py, urls.py       # Страницы и HTTP API
│   ├── services.py             # Транзакции, роли и переходы статусов
│   ├── domain.py               # Продукты, статусы и график платежей
│   ├── automatic_decisions.py  # Скоринг при обычной отправке
│   ├── scoring_sources.py      # Проверенные входные данные компании
│   ├── scorecard_workflow.py   # Применение результата к заявке
│   ├── scorecard/              # Проверка JSON и адаптер исходного движка
│   ├── mlcard/                 # Полный рабочий движок и card.yaml
│   ├── management/commands/    # Импорт данных и заполнение демобазы
│   ├── migrations/             # Последовательные изменения схемы БД
│   └── templatetags/           # Форматирование данных в шаблонах
├── templates/                  # HTML Django, кабинеты клиента и эксперта
├── static/                     # Исходные CSS, JavaScript и SVG
├── fixtures/                   # Единственные рабочие JSON-примеры и PDF
├── tests/                      # Все тесты: Django, модель, HTTP, JavaScript
├── scripts/                    # Запуск, контейнер, проверки
├── docs/
│   ├── reference/
│   │   ├── briefs/             # Исходные PDF и справочная статья
│   │   ├── text/               # Текстовые извлечения из PDF
│   │   ├── mlcard/             # Неизменённый оригинал для независимой сверки
│   │   └── input-format.md     # Описание входных JSON
│   └── reports/                # Исторические отчёты
├── manage.py                   # Команды Django
├── requirements.lock           # Зафиксированные зависимости
├── Dockerfile, compose.yaml    # Контейнерный запуск
└── README.md                   # Запуск и навигация
```

Локальные рабочие каталоги `.data/` (БД, доступы, резервные копии), `.venv/` (зависимости) и `staticfiles/` (собранная WhiteNoise-статика) исключены из Git. Они нужны работающему приложению. `.artifacts/` предназначен для новых временных отчётов проверок и тоже исключён из Git.

## Что упорядочено

- Git-метаданные перенесены из `alpha/.git` в корень. Коммиты, ветка `main` и `origin` сохранены; новые коммиты не создавались.
- Удалены `alpha/` и `alpha/alpha/`: обе копии были чистыми версиями того же коммита, без уникальных рабочих файлов, веток или stash. Освобождено 14 242 728 байт файлов после сохранения основной Git-истории.
- Удалены три побайтовых дубликата JSON из бывшей папки `доки/нововедение`; рабочие экземпляры находятся в `fixtures/scorecard/`.
- Все исходные материалы собраны в `docs/reference`, старые отчёты — в `docs/reports/2026-10-25-before-mlcard`.
- `credit/tests.py` перенесён в `tests/test_cabinet.py`, импорты и команды проверки обновлены.
- Удалён сгенерированный Python-кэш проекта: 61 файл, 573 612 байт. Сборка статики очищена от устаревших файлов и создана заново штатной командой Django.

Эталон `docs/reference/mlcard` не является лишним дубликатом: тесты независимо импортируют его и сверяют полный результат с рабочим `credit/mlcard`. Это позволяет обнаружить случайную подмену формул, весов или коэффициентов. Извлечённые тексты также используются для сверки требований без разбора PDF.
